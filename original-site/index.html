Station 03

Eval Hub — cross-product evaluation & safety

Live · methodology publicSafety & evals

The independent evaluation layer across VVDex products. Golden suites gate a production release—a CLI gate exits non-zero below baseline and blocks the deploy—while nightly adversarial probes measure safety.

  • A judge that must earn trust — the LLM judge stays advisory until calibrated against human labels: Cohen's κ = 0.79.
  • It caught real defects in production — an agent that missed implicit suicidal ideation, and candidate ranking influenced by nationality inferred from surnames—unlawful under the German AGG.
  • Estate-wide — three products: Conxto (gated) plus StandScout and the Agent Service Lab (measured). The harness proves contract-following; Eval Hub tracks wider quality and safety.

I also built the cross-model operating memory behind the work: connected project knowledge, code intelligence, tests and runtime evidence that let a new AI thread continue where the last one stopped instead of rebuilding context from chat history.
