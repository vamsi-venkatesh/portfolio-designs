    Cross-model AI operating memory

    Connected Vault intent to Project Brain code truth, governed execution, runtime evidence and reviewed write-back.

  9. Built Jul–Aug

    Agent Services, Studio and Eval Hub

    Built governed service contracts, executable graphs, public proof, a private control plane and an independent cross-product evaluation layer.
